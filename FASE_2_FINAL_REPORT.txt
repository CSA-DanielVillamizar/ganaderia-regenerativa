✨ PATRONES IMPLEMENTADOS
═══════════════════════════════════════════════════════════════════════════════

1. Pub-Sub Pattern (notificationService)
   • Listeners pueden suscribirse a cambios
   • Actualización reactiva de notificaciones
   • Sin dependencia de Redux/Context

2. Error Normalization (api-client.ts)
   • Convierte múltiples formatos a ErrorResponse
   • Captura traceId desde headers
   • Manejo automático de 401/400/409/500

3. Real-time Validation (useMovementValidation)
   • Validaciones onBlur antes de submit
   • Consultas paralelas a API
   • Cacheable y reutilizable

4. Axios Interceptors
   • Response interceptor para errores
   • Captura de headers personalizados
   • Auto-redirect en 401
